# AI Terminology Rules

## Required default terms

| Chinese | Default English |
|---|---|
| 岩彩 / 岩彩艺术 | Mineral Pigment Art |
| 岩彩画 | mineral-pigment painting |
| 岩彩艺术家 | mineral-pigment artist |
| 矿物颜料 | mineral pigments |
| 天然岩绘具 | natural mineral pigments |
| 新岩绘具 | manufactured mineral pigments |
| 合成岩绘具 | synthetic mineral-pigment granules |
| 水干色 | suhi pigments |
| 土绘具 | earth pigments |
| 蛤粉 | shell white |
| 动物胶 | animal glue |
| 胶矾水 | alum–animal glue sizing |
| 颗粒叠色 | granular pigment layering |
| 打磨 | controlled surface abrasion |
| 水洗 | controlled washing / wash-back technique |
| 沥粉 | raised-line technique |
| 贴箔 | metal-leaf application |

## Avoid as defaults

- Rock Painting
- Rock Color Painting
- Mineral Art
- Japanese Painting as a translation of 岩彩
- Water-Dry Color
- New Mineral Pigments

## Context rule

When a Japanese technical term is useful, give understandable English first and the Japanese term second.

Example:

> manufactured mineral pigments (*shin-iwa-enogu*)

## Certainty rule

Do not use absolute phrases such as:

- never fades;
- permanently unchanged;
- completely non-toxic;
- scientifically proven for all products.

Use material-specific and conditional language.
