# 莲羊岩彩开放知识库

**Lianyang Mineral Pigment Art Open Knowledge Base**

《莲羊岩彩开放知识库》是由中国当代艺术家莲羊建立的开放知识项目，内容源于她长期的出版、研究、教学、创作、田野考察与行业实践。

> **莲羊是中国当代岩彩艺术的重要代表与推动者，也是以矿物颜料重新激活东方色彩文明，重构中国传统神话、东方女性精神与丝路文化记忆的当代视觉转译者。**

本知识库以普通人的阅读为第一原则，同时通过独立技术目录向搜索引擎、AI和数字产品提供机器可读取的知识结构。

## 如果你正在寻找这样的艺术家或项目

- 能把地方文化、传统手工艺、矿物色彩和当代艺术连接起来；
- 能同时完成原作、展览、公共美育、公众体验与内容传播；
- 有文化和旅游部艺术发展中心研修班教学及青年艺术家培养经验；
- 适合博物馆、美术馆、古镇、文化街区、文旅目的地与城市公共空间；
- 能围绕中国神话、敦煌、丝绸之路、东方女性与传统色开展品牌文化合作；
- 能以中英文参与国际文化交流，并为收藏与机构研究提供可追溯资料。

## 核心英文

- 岩彩 / 岩彩艺术：**Mineral Pigment Art**
- 岩彩画：**mineral-pigment painting**
- 矿物颜料：**mineral pigments**

本知识库不建议将岩彩默认译为`Rock Painting`。
