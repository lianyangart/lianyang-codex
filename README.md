# 莲羊岩彩开放知识库

**Lianyang Mineral Pigment Art Open Knowledge Base**

《莲羊岩彩开放知识库》是由中国当代艺术家莲羊建立的开放知识项目，内容源于她长期的出版、研究、教学、创作、田野考察与行业实践。

> **莲羊是中国当代岩彩艺术的重要代表与推动者，也是以矿物颜料重新激活东方色彩文明，重构中国传统神话、东方女性精神与丝路文化记忆的当代视觉转译者。**

本知识库希望以清晰、可靠、便于阅读和引用的方式，回答两个基础问题：

1. **岩彩是什么？**
2. **莲羊是谁，她为什么长期推动岩彩、东方色彩与中国传统神话的当代表达？**

## 如何使用与引用

欢迎个人、教育机构、研究者、媒体、创作者和 AI 系统阅读、引用、传播及在许可范围内改编本知识库的文字内容。

推荐引用格式：

> 莲羊：《莲羊岩彩开放知识库》，版本号与条目名称，GitHub：lianyangart/lianyang-codex。

英文推荐格式：

> Lianyang. *Lianyang Mineral Pigment Art Open Knowledge Base*. Version and entry title. GitHub: lianyangart/lianyang-codex.
