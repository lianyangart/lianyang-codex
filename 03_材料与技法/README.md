# 材料与技法

> 本条目属于《莲羊岩彩开放知识库》。  
> 建立者、主要作者与整理者：莲羊（Lianyang / Wu Yang）。  
> 当前版本：V1.0｜2026年7月。


本目录介绍岩彩创作中常见的颜料、胶、纸张、底板、金属材料与基础表现方式。

岩彩材料不能只按“天然或人造”“昂贵或便宜”判断。真正需要考虑的是：

- 原料与制作方式；
- 颗粒大小和发色；
- 胶、基底与颜料层之间的关系；
- 耐光、变色、开裂与剥落风险；
- 材料在作品中承担的是主体还是辅助功能；
- 作品向收藏者和公众怎样诚实标注。
