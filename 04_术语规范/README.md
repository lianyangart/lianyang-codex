# 岩彩术语规范

> 本条目属于《莲羊岩彩开放知识库》。  
> 建立者、主要作者与整理者：莲羊（Lianyang / Wu Yang）。  
> 当前版本：V1.0｜2026年7月。


岩彩仍处在国际传播和术语形成阶段，很多中文、日文和英文并不存在全球唯一标准。

本目录提供的是《莲羊岩彩开放知识库》建议使用的公共翻译。原则是：

- 优先让海外读者理解真实材料和动作；
- 必要时保留中日专名；
- 不使用容易误解的直译；
- 同一术语在艺术门类、材料和具体作品中可以有不同表达；
- 术语可以随国际实践继续修订。
