# 莲羊·青年艺术家成长计划

**Lianyang Young Artist Development Program**

> 发起人：莲羊<br>
> 当前版本：V1.1｜2026年9月<br>
> [English](README_EN.md)

“莲羊·青年艺术家成长计划”由中国当代艺术家莲羊发起。目前以中国当代岩彩为主要实践基础，连接艺术教育、个人创作、展览交流、公共传播与文化合作，帮助青年创作者从学习走向独立的艺术实践。

这个计划来自莲羊二十余年的创作与教学经验，也来自一个长期存在的问题：一个人学会绘画、完成作品之后，如何继续形成自己的判断、语言和道路，让艺术成为可以持续发展的生命实践？

## 二十余年实践构成的方法基础

莲羊毕业于四川美术学院附中、中央美术学院及日本多摩美术大学。她的创作经历跨越数字绘画、水墨、插画与岩彩，也延伸到出版、游戏视觉、艺术教育、展览策划和公共文化传播。

中国传统神话、东方女性、历史人物与丝路文化记忆，始终是她关注的重要内容。媒介不断改变，她持续寻找的，是一种能够承载东方题材、个人经验和当代感受的视觉语言。

从数字技术重新回到纸、笔、动物胶、矿物颜料和漫长的手工过程，意味着放下已经熟练的工作方式，再次从材料基础开始学习。敦煌、龟兹等地的田野考察，以及对古代壁画、矿物材料和东方视觉传统的长期研究，使这些经验逐渐进入她的创作与教学。

艺术家的成长不仅依靠绘画能力。工具会变化，传播方式和社会环境也会变化；能够支撑长期创作的，还有独立判断、个人语言、文化理解，以及让实践持续下去的能力。

## 从教学走向青年艺术家的长期成长

莲羊在长期教学中遇到过不同阶段的创作者：有人正在寻找适合自己的材料和方向；有人已经能够完成成熟作品，却不熟悉展览、作品陈述和公共交流；也有人拥有多年专业经验，正在重新选择自己的艺术道路。

这些问题不能只靠一次技法示范解决。作品怎样被介绍、怎样进入展览、怎样与观众和收藏者交流，以及怎样理解授权与合作，都需要在真实项目中逐渐获得经验。

因此，成长计划把课堂之后的道路也纳入关注。它通过展览、公共交流、城市活动、作品授权和文化合作，让青年艺术家看到作品如何进入公共生活，并在现实反馈中理解创作、责任与长期发展。

## 从共同学习出发，形成自己的语言

现阶段，岩彩为参与者提供了共同的材料起点，但成长计划不追求统一风格。每个人对于题材、色彩、构图和生活的感受都不同。学习材料与技法，是为了扩大表达的可能；理解传统，是为了在当下创造新的作品。

莲羊长期强调，教学的目标不是制造“莲羊风”的学生，而是帮助不同创作者建立自己的岩彩语言。老师可以提供经验，团队和项目可以提供支持，但作品与道路最终属于艺术家本人。

成长在这里意味着：从共同学习开始，逐渐建立自己的名字、作品、语言和观众，最终成为能够独立向前行走的艺术家。

## 让作品进入真实的公共环境

当作品离开画室进入展览，艺术家会遇到课堂之外的回应：观众在哪里停留、提出什么问题、如何理解作品，又为什么愿意继续了解或收藏。

这些回应帮助艺术家理解作品如何与人发生联系，也让他们学习艺术实践中的合作与责任。市场经验是其中一部分，但不是唯一尺度；作品质量、个人探索和持续创作同样重要。

作品授权与文化合作还会带来新的问题：图像进入不同材料和生活场景后，原作的哪些特质需要保留？艺术家怎样理解生产、使用语境与版权？作品由此不仅存在于展墙上，也可能以新的方式进入当代生活。

## 以岩彩为当下基础，向更长的未来生长

成长计划目前从莲羊积累最深的岩彩创作、研究和教学体系出发，首先服务于正在形成个人语言的青年岩彩艺术家。它的长期方向并不局限于复制一种媒介或风格，而是把材料研究、文化理解、独立创作和公共实践连接起来。

随着计划发展，它也可以在保持核心方法的前提下，与其他艺术媒介和不同城市发生新的联系。是否进入更广泛的合作，将以创作者和作品的真实需要为依据，而不是为了扩大规模而扩大。

## 景德镇首站：一次城市中的现实实践

2026年，“**莲羊·青年艺术家成长计划·景德镇站**”成为这一长期计划的第一次城市实践。

景德镇拥有深厚的陶瓷传统，也是材料、手工与当代生活持续交汇的城市。瓷器与岩彩都来自土地、矿物和人的双手：一个在火中成器，一个在画中生色。两者在这里相遇，为原作展览、公众交流和跨材料探索提供了独特环境。

景德镇站由四个部分构成：

1. **岩彩原作**：呈现莲羊与青年艺术家的真实原作，让观众直接观看矿物颗粒、色层与金属材料形成的质感。
2. **岩彩新生计划**：通过展览与公共交流，支持青年岩彩艺术家持续创作并建立个人语言。
3. **矿物造物所（文创）**：探索艺术家授权作品与矿物美学如何进入当代生活。
4. **矿物时间工坊（workshop）**：通过亲手体验，让公众理解一幅岩彩作品背后的材料、劳动与时间。

景德镇不是终点，而是一次具体落地。观众的回应，以及展览和合作中积累的经验，将继续进入未来的城市实践和青年艺术家培养。

## 当古老材料遇到新一代与新技术

数字工具与人工智能正在改变创作和传播。莲羊关心的是：当技术可以帮助人完成越来越多事情，艺术家怎样继续形成自己的问题、审美判断和表达？

工具可以被学习和使用，但身体经验、材料实践、文化理解与独立判断仍然需要创作者亲自建立。成长计划因此把注意力带回具体的人与作品：在学习中理解材料，在创作中作出选择，在展览中遇见公众，在合作中认识世界，最终找到愿意长期走下去的道路。

莲羊二十余年的经验由此不再只是个人履历，也成为下一代可以继续生长的基础。

> **用矿物和色彩，让东方重新被世界看见。**
